# הוראות הפעלה — App Vault

## הכנה חד-פעמית

1. פתח הגדרות Android → אודות הטלפון.
2. לחץ שבע פעמים על "מספר Build" עד שאפשרויות למפתחים מופעלות.
3. חזור להגדרות → מערכת (או הגדרות נוספות) → אפשרויות למפתחים.
4. הפעל "ניפוי שגיאות אלחוטי" / Wireless debugging.
5. בחר "צימוד מכשיר באמצעות קוד צימוד" / Pair device with pairing code.
6. השאר את חלון הקוד פתוח. פתח את App Vault במקביל באמצעות מסך מפוצל.
7. ב-App Vault לחץ Pair ADB והזן כתובת IP, את יציאת הצימוד ואת הקוד בן שש הספרות.
8. לאחר הצימוד, חזור למסך הראשי של Wireless debugging. הזן ב-App Vault את יציאת החיבור שמוצגת שם ולחץ Connect.

יציאת הצימוד ויציאת החיבור הן שתי יציאות שונות. אין להעתיק את יציאת הצימוד לשדה Connect.

## גיבוי ושימור נתונים

1. לחץ Export APK bundle ליד האפליקציה.
2. שמור את קובץ `.avbackup` במיקום חיצוני לבחירתך.
3. רק אחרי שהייצוא הסתיים, אשר Preserve & uninstall.
4. Android ישאיר את תיקיית הנתונים במכשיר. הקובץ החיצוני אינו מכיל אותה.
5. כדי להתקין מחדש, לחץ Restore a .avbackup file, בחר את הקובץ, אפשר התקנת אפליקציות ל-App Vault ואשר את מסך ההתקנה של Android.

## אזהרה

אל תסיר את אפליקציית היעד דרך מסך Settings → Apps → Uninstall. פעולה רגילה עלולה למחוק את הנתונים. כדי לשמר אותם, ההסרה חייבת להתבצע מתוך App Vault באמצעות פקודת `pm uninstall -k`.

הנתונים אינם מגובים לקובץ ולכן לא ישרדו איפוס מכשיר, ניקוי נתוני האפליקציה, מעבר למכשיר אחר או מחיקה נפרדת של הנתונים. שמור את אפליקציית App Vault מותקנת עד שהתקנת מחדש את אפליקציית היעד.
